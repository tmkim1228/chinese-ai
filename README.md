Chinese with AI v1.0 (English edition)

Paste Chinese text and press Ask AI for a full English translation, a short context note, and a word-by-word list (hanzi, pinyin with tone marks, English meaning).

Your API key is stored only on this device. Text is sent only to the provider you choose (xAI, OpenAI, or Gemini), and only when you press Ask AI.

Tap any Chinese character for the traditional form, pinyin, and English meanings from the offline dictionary (Unicode Unihan + CC-CEDICT). Add words to Review for spaced repetition (Leitner boxes at 1, 3, 7, 14, 30, and 60 days), quizzes, and a progress chart. Export a JSON backup of your review list.

This English edition does not include Korean readings or HANZI DAILY memory stories. The Korean-language edition continues as a separate app.

Install the PWA from the site, or open ChineseAI-en-v1.0.html in Chrome or Edge. The dictionary works offline after the first load; Ask AI needs a network connection.

Data: Unicode Unihan (Unicode Terms of Use); Jun Da frequency list (academic/educational, with attribution); CC-CEDICT (MDBG, CC BY-SA 4.0, https://creativecommons.org/licenses/by-sa/4.0/, https://www.mdbg.net/chinese/dictionary?page=cc-cedict, release 2026-11-06).
