Readings

When this is on, the Text analysis under Ask AI shows pinyin and Korean 훈음 (for example shuǐ / 물 수) under each character. It is off by default so the English edition stays English-only. 음 comes from Unicode Unihan (kHangul). 훈 comes from the 훈음 data already used in the Korean edition (libhangul hanja.txt, BSD-3-Clause).

When this is also on, the Ask AI prompt asks the model to add pinyin and Korean 훈음 after each hanzi in the word-by-word list. It stays off until you turn it on.

What this app does

  • Ask AI — Paste Chinese text and get a full English translation, a short usage note, and a word-by-word list.
  • Dictionary — Look up characters and words offline (pinyin and English from CC-CEDICT).
  • Review — Save words and review them with spaced repetition, quizzes, and a progress chart. The list stays in this browser; export a JSON backup.
